# BotLoom

BotLoom בונה סוכנים שמדברים עם לקוחות ואוטומציות לעבודה השוטפת, מתוך תיאור במילים. כותבים בעברית או באנגלית מה הסוכן צריך לעשות, ו-Claude מתכנן את הזרימה, הפרסונה ומאגר ידע ראשוני. אחר כך משפרים על קנבס ויזואלי, מחברים לוואטסאפ, טלגרם, Slack, Discord או לאתר, ורואים כל הרצה צעד אחר צעד.

## מה Claude עושה במערכת

- **מתכנן סוכנים:** מנסח את הזרימה, מריץ עליה בדיקות ומתקן את הטיוטה שלו כשבדיקה נכשלת.
- **עורך זרימות לפי בקשה:** כותבים "תשלח לי הודעה בסלאק על כל ליד חדש" ומקבלים רשימת שינויים מוצעת. שום דבר לא נשמר עד שלוחצים Apply.
- **עונה עם כלים:** חיפוש במאגר הידע, חיפוש שורה בגוגל שיטס, בדיקת שעות פנויות ביומן, קביעת תור עם הגנה מכפל הזמנות, שליחת מייל, קריאה ל-API, זיכרון על הלקוח והעברה לנציג.
- **זוכר לקוחות:** פרטים שהלקוח מספר נשמרים לשיחות הבאות. מספרי כרטיס וסיסמאות נדחים, והצוות יכול למחוק כל פרט מהתיבה.
- **כותב תקציר העברה:** כשהשיחה עוברת לנציג, Claude כותב מה קרה, מה הלקוח רוצה, מצב רוח, דחיפות והצעד הבא.
- **מנסח תשובות לצוות:** כפתור "Draft reply" כותב טיוטה מתוך השיחה ומאגר הידע.
- **כותב טקסט בתוך אוטומציות:** למשל מייל תודה אישי להזמנה, עם מסלול גיבוי אם הקריאה נכשלת.

## ערוצים וחיבורים

WhatsApp Cloud API, טלגרם, ווידג'ט לאתר עם תמיכה מלאה בימין לשמאל, Slack ו-Discord להתראות לצוות, Google Sheets, Calendar ו-Gmail (במצב sandbox מתועד כשאין הרשאות), בקשות HTTP, וובהוקים ותזמון.

## דוגמאות מוכנות

מרפאת תנועה (קבלה בעברית עם קביעת תורים), תמיכה לחנות Gadget Garden, ואוטומציית הזמנות. כולן רצות מקצה לקצה גם בלי מפתחות.

## הפעלה

```bash
npm run install:all
npm run build
npm start   # http://localhost:8787
```

כדי לקבל תשובות אמיתיות מ-Claude מוסיפים `ANTHROPIC_API_KEY` לקובץ `.env`. בלי מפתח עונה ספק דמו קבוע, כך שהמערכת וכל 37 הבדיקות רצות גם בלי רשת.
