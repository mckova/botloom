# 🧶 BotLoom: פלטפורמת AI נייטיב לבניית סוכנים ובוטים

**מתארים את הבוט במילים, בעברית או באנגלית, ו-Claude בונה אותו.** אחר כך משפרים אותו בבילדר ויזואלי, נותנים לסוכני
Claude כלים אמיתיים (Google Sheets, יומן גוגל, Gmail, API חיצוני, מאגר ידע), מחברים ל**וואטסאפ, טלגרם ולאתר**, ורואים
כל הרצה צעד אחר צעד.

## מה יש בה

- **מעצב AI:** כותבים מה הבוט צריך לעשות, ו-Claude מתכנן את הזרימה, הפרסונה ומאגר ידע ראשוני. הוא גם מריץ בדיקות על
  הגרף, ואם הן נכשלות הוא מתקן את הטיוטה שלו בעצמו.
- **סוכני Claude עם כלים:** חיפוש במאגר הידע, שמירת ליד בגיליון, קביעת תור ביומן, שליחת מייל, בדיקת הזמנה ב-API והעברה
  לנציג. בנוסף, **כל צומת בזרימה יכול לשמש ככלי** בעזרת `{{ai.field}}`.
- **ניתוב כוונות וחילוץ נתונים בעזרת AI**, עם פלט מובנה (JSON Schema).
- **שיחות שנעצרות וממשיכות:** צומת "שאלה" עוצר את הריצה עד שהלקוח עונה. הוא כולל בדיקת תקינות (מייל, טלפון, תאריך,
  מספר, בחירה) וניסיונות חוזרים.
- **ערוצים:** WhatsApp Cloud API (עם אימות חתימה), טלגרם, ווידג'ט לאתר (תומך RTL ושומר היסטוריה), וובהוקים ותזמון.
- **תיבת נציגים:** כשהשיחה עוברת לנציג אנושי, הבוט שותק. הנציג עונה מהדשבורד ומחזיר את השיחה לבוט.
- **שקיפות מלאה:** כל ריצה נשמרת כ-trace: אילו צמתים רצו, אילו כלים נקראו, כמה טוקנים נוצלו וכמה זמן זה לקח.
- **עובדת גם בלי מפתחות:** כל ההדגמה וכל הבדיקות רצות במצב דמו.

## הפעלה

```bash
npm run install:all
npm run build
npm start   # http://localhost:8787
```

כדי לקבל תשובות אמיתיות מ-Claude מוסיפים `ANTHROPIC_API_KEY` לקובץ `.env`.
